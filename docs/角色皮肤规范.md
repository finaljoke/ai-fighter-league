# 角色皮肤 · 规范

一个角色由两部分组成：**身体参数**（`bodies.py`，模拟用，决定打得怎么样）和**外观**（立绘，只决定长什么样）。
画面里的骨骼按模拟摆，网格按立绘做，两者在下面"比例约定"里对齐。以后加角色，只要按这份规范交立绘、标关节点、跑工具，
不用改代码；体型怎么特殊、身体参数在赛季里怎么变，都由同一套规则处理。

流程：先在 `bodies.py` 定义身体参数 → 画师交三视图（`characters/`）→ 标关节点（`characters/<id>.rig.json`）→
`tools/build_skin.py` 生成皮肤（`characters/<id>.skin.json`）→ 核对 → 页面自动用上。`characters/` 不进仓库。

## 比例约定：什么听模拟的，什么听立绘的

| 尺寸 | 听谁的 | 为什么 |
|---|---|---|
| 身高 | 模拟（`bodies.py` 的臂展换算，同 `viz.js` 的 `build`） | 立绘都按同一个模板画，画面上一样高，表达不了身高差 |
| 胳膊总长（肩到拳套中心） | 模拟（臂展） | 出拳够不够得着是模拟算的，画面要和它一致（所见即模拟）。立绘和臂展不一致的部分**均匀摊在整条胳膊上**，上臂、前臂按立绘的比例分 |
| 其余骨长（躯干、大腿、小腿、脖子、踝高） | 立绘 | 只影响画面，不影响胜负。脖子只算顺着脊柱的那段，头往前探的部分不算 |
| 粗细、形状（每一圈截面）、头、拳套、脚 | 立绘 | |
| 站姿屈膝的程度 | 固定 | 两脚前后分开 0.22 米站着时，腿离伸直差腿长的 6.5%（膝盖弯四十度上下），按立绘的腿长算骨盆高度。不照原来骨架的蹲法：原来的腿比真人长，照它蹲人就矮一截；再少，轴转、滑步时脚够不着 |
| 肩宽、胯宽、头半径、胸腹厚、拳套半宽、拳套中心到拳面 | 立绘（`build_skin.py` 量出来写进皮肤） | 画面里判"拳打到哪、挡在哪"用这些数，换成立绘量的，拳面正好碰到网格表面 |

`build_skin.py` 会报胳膊拉长了多少：超过 15% 说明立绘和臂展设定差得多，跟画师或数值确认。现在陆烬 +3%、顾晏 +4%。

骨长全靠关节点，**标偏几厘米画面就走样**：肩线标低了，上臂变短（肩头挤成一团）、脖子变长；胯、膝标低了，腿变短，整个人蹲着显矮。
所以工具会报肩、胯、膝离地占身高多少，和真人比（见下面"标注"）。

**身体参数在赛季里会变**（称重、增肌）：画面按 `build` 的粗细比例加减，躯干跟胸围、胳膊跟肌肉量、腿跟腿粗、脖子跟抗击打；
头、拳套、靴子、脚不变。身高变了，长度按比例缩放。皮肤里记着做皮肤时的身体参数（`ref`），不用重做皮肤。

**没有立绘的角色**（陪练教练、实验体）：按身体参数和配色（`viz.js` 的 `LOOK`）生成素色三维，同一套截面结构、同一种画法。
页面里只要有一个出场角色有皮肤，整页都画三维；一个都没有就画 2D 小人。

## 立绘要求（给画师）

| 项 | 要求 |
|---|---|
| 构图 | 一张图里三个视图，从左到右：正面、左侧面（面朝图左，看到的是角色的左侧）、背面 |
| 投影 | 正交，不要透视；三个视图同一比例、同一条地面线，头顶、肩、胯、膝、踝在三个视图里同高 |
| 姿势 | A 字站姿：胳膊离开身体约 20°，**胳膊和躯干之间、两腿之间要露出背景**；拳套戴好、拳面朝下，脚尖朝前 |
| 背景 | 纯色浅灰（可以有很淡的渐变），地面影子越淡越好；人身上不要有和背景一样的灰色大块 |
| 穿戴 | 拳套、绷带、短裤、靴子都画上；短裤腰头和皮肤颜色要分得开（工具按颜色找腰头和裤脚） |
| 尺寸 | 至少 1500×1000，人物高至少 900 像素 |

现在的 `red1.jpg`（陆烬）、`black1.jpg`（顾晏）都符合。换装（不同短裤、拳套）要重画三视图、重新生成。

## 标注：`characters/<id>.rig.json`

只标关节点，其余从轮廓推。坐标是立绘上的像素（x 往右、y 往下）。

| 键 | 是什么 |
|---|---|
| `image` | 立绘路径 |
| `ground` | 脚底那一行的 y（三个视图共用） |
| `views` | `front` / `side` / `back`：`[起始 x, 结束 x, 中线 x]`。正面、背面的中线是身体左右对称的那条线；侧面的第三个数是骨盆关节的 x（前后方向的零点） |
| `joints` | 关节点：`f` 是正面的 `[x, y]`，`s` 是侧面的 `[x, y]`。左右按角色自己的左右（正面图里角色的右边在图左） |

关节点（都标关节中心，不是轮廓）：

| 名字 | 标在哪 |
|---|---|
| `pel` | 骨盆：两个胯关节连线的中点（正面在中线上，侧面在胯关节） |
| `chest` | 两肩关节连线的中点 |
| `head` | 头心：颅骨中心，大约在眼睛和耳朵之间（不算头发） |
| `chin` | 下巴尖那一行（只用它的高度） |
| `shR` `shL` | 肩关节：锁骨那条线往下一点，三角肌的顶上（不是三角肌鼓起来那块的中心，那里低了两三厘米） |
| `elR` `elL` | 肘关节 |
| `wrR` `wrL` | 手腕：拳套袖口和绷带交界处 |
| `gcR` `gcL` | 拳套中心 |
| `gtR` `gtL` | 拳套最下端（拳面） |
| `hipR` `hipL` | 胯关节（大转子的高度，和 `pel` 同高）。被短裤挡住看不见，按离地占身高 0.52 估 |
| `knR` `knL` | 膝关节：髌骨下缘，膝盖最细的那一行 |
| `anR` `anL` | 踝关节（内外踝的高度；穿靴子就估） |
| `toe` `heel` | 只标侧面：鞋尖、鞋跟的最前、最后点（贴地） |

标完先看工具报的"关节离地占身高"（身高从地面到头顶，头顶不算头发：头心往上和往下到下巴一样远）：
真人肩约 0.82、胯约 0.52、膝约 0.28，差 0.02 以上回去看标注。现在陆烬 0.817 / 0.522 / 0.279，顾晏 0.816 / 0.519 / 0.282。

推出来的（推错了在标注里写同名的键覆盖）：

| 键 | 推法 |
|---|---|
| `rows.hairTop` | 正面轮廓最上面一行 |
| `rows.neckBase` | 脖子根：两肩连线往上，到下巴的 35% |
| `rows.waist` | 腰头上沿：正面中线往下，颜色离开胸口皮肤的第一行 |
| `rows.crotch` | 裆：两腿之间第一次露出背景的那一行 |
| `rows.hem` | 裤脚：沿右腿往下，颜色回到皮肤的第一行 |
| `split` | 正面里胳膊和躯干的分界：从胳肢窝（胳膊和躯干第一次分开的那一行）斜到脖子根旁边 |
| `sideArm` | 侧面里胳膊挡住的地方：沿侧面的肩、肘、腕、拳套连一串胶囊，粗细按正面同一处的宽度和侧面拳套的长度 |

## 生成和核对

```powershell
py -m pip install pillow scipy                                  # 第一次
py -X utf8 tools/build_skin.py LJ GY --debug 核对目录             # 生成 characters/<id>.skin.json
py -X utf8 tools/viz_check.py --page --skin                     # 按皮肤的骨长逐拳核对，出核对页 runs/viz_check_skin.html
node tools/audit_rig.mjs --skin                                 # 按皮肤的骨长体检（关节跳变、穿插）
node tools/preview_frames.mjs runs/viz_check_skin.html 截图目录 "7@20,4@1.2@2,5@26.85@2"   # 看几帧
```

每次新做或改了皮肤，四件事都要过：

1. **核对图**（`核对目录/<id>/overlay.png`）：青、黄、紫三色的截面线贴着正面、侧面、背面的轮廓走；绿线是推出来的胳膊分界和侧面胳膊，
   要正好把胳膊（含绷带、拳套）盖住。`side_inpainted.png` 是侧面补色图，胳膊挡住的地方补成身体的颜色，皮肤和短裤不互相串色。
2. **工具的报告**：胳膊拉长不超过 15%；关节离地占身高和真人差不到 0.02；骨长、头半径、肩宽、拳套这些数在常识范围里；推出来的几行和核对图对得上。
3. **逐拳核对全部对上**（`viz_check.py --skin` 最后一行）。
4. **看截图**：打中（拳面贴在落点上）、被挡（停在护手上）、缠抱（不穿模）、倒地（躺平、脚尖朝上）、训练馆和开场卡。

页面生成时有皮肤就自动用：`make_episode.py`、`season.py`、`render_season.py` 按出场角色读 `characters/<id>.skin.json`，
加 `--no-skin` 画回 2D 小人。导出视频会等贴图加载完（`EXPORT.ready`）。

## 网格怎么做、怎么动

**网格**：每段身体（躯干、头颈、两臂、两腿、两脚）是沿骨骼一圈圈的截面，每圈记 `[k, v, ox, oy, rx, ry, tw]`：
在第 k 段骨头的比例 v 处（k = -1 或段数时是首尾往外延的米数），截面是中心偏移 (ox, oy)、半轴 (rx, ry) 的超椭圆，tw 是躯干、头颈的扭转比例。
截面量法：正面量左右宽、侧面量前后厚；胳膊在侧面挡在身子前面量不出厚，按左右宽算。管子两头收成圆顶（三角肌顶、大腿根往外接，拳面、脚尖脚跟往里收）。
胳膊从肩关节起，往外只接 2.5 厘米圆顶，正好到立绘的肩膀轮廓；躯干顶只收 3 厘米。哪个长了，护架时三角肌顶都会从躯干上戳出一个包。

**贴图**：顶点朝前贴正面、朝后贴背面、朝两侧贴侧面，交界处按法线方向渐变。右侧当成左侧的镜像。
侧面里躯干、大腿被胳膊挡住的地方贴补色图（按同一行胳膊两边露出来的颜色接上，再反复取四邻平均抹匀，腰头上沿、裤脚两行是分界）。

**每一帧**（`viz.js` 的 `SKIN`）：
- 骨骼还是原来那套（模拟的位置、朝向、动作时间，`bodyPose`、`armsOf`），只是骨长和身体尺寸换成皮肤量的（`fit`）。
- 截面在骨头上按比例走，往外延的按米数走（头顶、拳套、脚不跟着骨头拉长）。躯干从胯的朝向扭到肩的朝向，头颈从躯干的朝向转到脸的朝向（盯着对手），
  胳膊、腿的截面沿骨头一圈圈传下去（最小旋转，不凭空拧转）；三角肌顶、大腿根大体跟着躯干，只跟着骨头转四分之一。
- 两个人放进同一个深度缓冲里画，谁挡谁逐像素按离镜头远近算；投影和 2D 一模一样（转播机位 `makeCam`、侧面机位 `sideCam`），画完贴回画布，
  擂台、器械、火花、名牌照旧用 2D 画。头部挨重拳那一下脸上一白；倒地、躺着时脚尖朝上。

## 已知局限

| 局限 | 原因 | 要解决得怎么做 |
|---|---|---|
| 背面、右侧是推出来的 | 三视图只有左侧面，右侧当成镜像 | 画师加一张右侧面，工具按四个方向分贴图 |
| 短裤侧面被拳套挡住的那块是糊的 | 那块立绘里看不到，只能补色 | 加一张胳膊抬起来的侧面图，或者画师单独画短裤侧面 |
| 腋下、腿内侧、头顶的贴图拉长 | 三视图都看不到这些面 | 同上，多一个视角 |
| 表情不动，只有挨打闪白 | 贴图是立绘上那一张脸 | 画几张表情（挨打、咬牙、累），按心态、挨打换脸部贴图 |
| 头发是贴在形状上的图，不是一缕缕的 | 形状只按轮廓量 | 头发单独做成几片网格 |
| 立绘表达不了臂展差别，长臂的角色胳膊会均匀拉长 | 立绘都按同一个模板画 | 画师按臂展设定画胳膊长度 |
