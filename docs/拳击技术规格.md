# 拳击模拟器 v2 · 技术规格

原则：**先能打拳击，再延伸到别的流派。** 每个技术动作都要在对局里起到和现实中相同的作用。
每一条"作用"都写成了自动测试（`test_techniques.py`），模拟器改动后必须全部通过。

**胜负只有三种：KO、TKO、点数判定。** 体力、精力（体能）、晕眩都只是资源池，耗光会导致倒地或被终止比赛，但本身不判胜负。

奖励只围绕胜负：打出裁判会计分的有效拳 +、被对手打中计分拳 −，击倒 ±，最后 KO / TKO / 判定赢 +1、输 −1，平局双方都算没赢。
奖励里不出现血量。保护体力是为了不被 KO / TKO，这层关系让 AI 自己学。
性格和打法不写进奖励，由身体条件和对局经历长出来，并且会随训练和比赛继续变化。

## 角色模型：什么决定一个角色在这一局的发挥

| 层 | 因素 | 是什么 | 怎么影响比赛 |
|---|---|---|---|
| 先天 | 身体属性 | 臂展、体重、力量、手速、步速、体能、抗击打、反应 | 每一招的射程、伤害、快慢；移动、转身；资源池大小。**属性预算制**：每项按范围折成 0~10 分，同一量级的角色总分相同（7 项身体 + 2 项心智 = 45 分），长处要用短处换；体重不算分，由量级限定（第一季中量级 69.9~72.6 公斤）；天赋熟练度的总量也相同，只是分布不同 |
| 先天 | 天赋熟练度 | 出身带来的 23 项技术起点 | 见"熟练度" |
| 先天 | 性格 | 胆量、沉着、斗志、冲动 | 改变心态对事件的反应：胆小挨打掉得多；沉着基准高、回得快；好斗打中涨得多、一后退就掉；冲动的被反击或被骗会上头 |
| 先天 | 心智 | 观察力、拳商 | 观察力：读招学得快，看对手体能、心态看得准，看得出露馅，能看穿一部分虚晃。拳商：出昏招少（心态差时昏招翻倍），训练时学得快 |
| 后天 | 流派 | 外围拳击 / 压迫型 / 重炮手 / 反击型 / 全能型 | 定默认架势，给天赋加成，决定训练时哪些技术练得勤 |
| 后天 | 熟练度 | 每项技术练到的水平，随训练演化 | 这一招的快慢、轻重、耗体能、准度、防守窗口 |
| 后天 | 习惯（癖好） | 从比赛里统计出来的规律 | 会被对手的读招记忆抓住；练得差的拳（< 0.35）起手会露馅，被眼尖的对手早一帧看到 |
| 赛前 | 训练 | 自我对练 + 流派练习倍率 | 熟练度往哪个方向长 |
| 赛前 | 当天状态 | 每场开打前定下（−1~1） | 伤害 ±8%、体能回复 ±10%、心态基准 ±5 |
| 赛前 | 战术计划 | 自由发挥 / 外围控距 / 压迫打身 / 防守反击 / 重拳抢攻 / 稳拿分数 | 限制一部分选择（被限制的动作每帧只有 25% 时候可选），不碰奖励。角落赛前把每个计划和对手模拟一回合排名，选第一名；某回合多数裁判判输就换下一个 |
| 赛中 | 架势 | 标准高位 / 长架 / 低姿抱架 / 低手位，可随时换（要花几帧） | 长架：直拳射程 +5%，对手头部直拳 ×0.85，勾拳 ×1.1。低姿：头部直拳 ×0.8，上勾拳 ×1.25，下潜窗口 +1，走得慢。低手位：刺拳快 1 帧、反应快 1 帧、闪躲窗口 +1，但举架只剩一半效果 |
| 赛中 | 站架 | 正架 / 反架，可以换 | 一正一反时：后手直拳射程 +5%、伤害 ×1.1，前手勾拳 ×1.1，刺拳 ×0.85 |
| 赛中 | 心态、读招 | 见下面三组核心 | |

所有这些都是数值，存在角色卡里，每个版本都存档。性格、心智、熟练度会随经历演化（熟练度已经接入训练，性格和心智的演化放到赛季系统里做）。

## 比赛的三组核心

| 核心 | 模拟里靠什么成立 |
|---|---|
| **猜拳** | 攻防互相克制，没有万能招：高位格挡克头部直拳，上勾拳克高位格挡和下潜，下潜克勾拳，勾拳克侧闪，身体拳克高位格挡，护体克身体拳又空出头部。刺拳起手 3 帧，约等于人的反应时间，只能预判不能看了再躲。 |
| **读招** | 每个人都记着这场比赛里对手爱出什么拳、拿什么防我的拳、虚晃多不多（按事件做平均，按反应延迟才"看见"，虚晃在收回那一刻才露馅）。所以"他一挨刺拳就下潜"这种习惯会被抓住，打法太单一会吃亏。 |
| **冒险** | 重拳打空收招长，被反击伤害 ×1.3、致晕 ×1.6；勾拳、上勾拳要进内围才打得到。落后的一方要不要搏，是真实的取舍。 |
| **策略** | 3 回合体能分配；身体拳的效果要到后面回合才显出来；知道自己在记分卡上领先还是落后，领先可以稳，落后得搏。 |
| **精准** | 射程、角度都是精确判定；打在射程最边缘只是擦到（60%）；贴身直拳打不开；拍挡的时机窗口只有 3 帧。 |
| **气势压制** | "心态"是一个资源池：打中、防住、把对手困在围绳上会涨；挨打、被击倒、被压在围绳上、重拳打空会掉。 |
| **心理战** | 虚晃骗出对手的防守动作会让他心态掉。心态低于 40 反应慢 1 帧，低于 20 慢 2 帧，低于 30 紧张掉体能，低于 15 出拳犹豫多 1 帧。对手能大致看出你的心态（身体语言），所以压制是看得见、能利用的。 |

## 擂台和时间

- 二维方形擂台，围绳内 6.1 米见方（20 英尺）。有围绳和角落，背靠围绳时退不了、也后仰不了。
- 1 帧 = 0.05 秒。正式比赛 3 回合 × 60 秒，回合间休息直接结算恢复。
- 双方会自动转身面向对手，但转身有速度上限，出拳、收招、挨打时转得更慢。
  所以**角度**是真实存在的：绕到对手正面线以外，他的防守打折，他也打不到你，要先转过来。

## 进攻：12 种拳

| 拳 | 现实中的作用 | 模拟里怎么体现 |
|---|---|---|
| 前手直拳（刺拳）·头 | 最快最远，量距离、扰乱、开路、控距 | 起手 3 帧最快，射程最远，耗体能最少，伤害小 |
| 前手直拳·身 | 打乱对手的防守高度 | 打在身上：伤体能，伤害小 |
| 后手直拳·头 | 主力重拳，配合刺拳打 1-2 | 起手 5 帧，伤害大，射程接近刺拳；打空了收招长、容易被反击 |
| 后手直拳·身 | 远距离打身体 | 同上，打身体 |
| 前手勾拳·头 | 近距离 KO 拳，从侧面绕过高位格挡 | 射程短（0.7 倍臂展），对高位格挡只减 65%，致晕能力强，会把对手的身体打歪 |
| 前手勾拳·身（肝脏拳） | 打肝脏，累积起来能直接打倒 | 体能伤害大，单独累积"身体伤"，满了直接倒地 |
| 后手勾拳·头 / 身 | 更重的勾拳，更慢 | 起手 6 帧，伤害最大 |
| 前手上勾拳·头 | 贴身时从中间撕开高位格挡，专打下潜 | 射程最短（0.55 倍），高位格挡只减 25%，打在下潜的人身上伤害 ×1.4 |
| 后手上勾拳·头 | 更重的上勾拳 | 同上，更慢更重 |
| 上勾拳·身（心窝） | 贴身打身体 | 打身体，体能伤害大 |

通用规则：

- **弯臂拳的射程**：直拳吃满臂展优势；勾拳是弯臂拳，只吃一半，上勾拳只吃 40%（其余按普通臂展算）。所以长臂的人勾拳够不到短臂的人刺拳那么远。
- **组合拳**：左右手交替时，下一拳可以在上一拳收招后半段直接起手，比同一只手连打快。所以 1-2、1-2-3 有真实的速度优势。
- **反击拳**：打在对手起手中、或对手打空后收招中，伤害 ×1.3、致晕 ×1.6。所以"看不见的那一拳"最容易打倒人。
- **贴身直拳打不开**：距离太近时直拳伤害减半；勾拳、上勾拳不受影响。所以内围要换勾拳、上勾拳。
- **打空更累**：没打中多扣一半体能。
- **打身体会暴露头部**：出身体拳的起手和出拳过程中，自己挨头部拳算反击。
- **体能**：越累伤害越低、步子越慢；身体伤会压低体能上限。

## 防守

| 技术 | 现实中的作用 | 克制 | 被克制 |
|---|---|---|---|
| 高位格挡（可边压边走） | 挡头部直拳最有效 | 头部直拳只吃 15% | 上勾拳（吃 75%）、身体拳（吃 60~70%）、角度 |
| 护体（肘部下沉） | 挡身体拳 | 身体拳只吃 20~30% | 头部拳几乎全吃 |
| 拍挡 | 时机对就拍开直拳，对手失去平衡 | 头部直拳完全拍开，对手多 4 帧收招 | 勾拳、上勾拳、身体拳拍不了 |
| 侧闪（闪身） | 头离开直拳的线路，顺势反击 | 头部直拳完全躲开，对手多 2 帧收招 | 勾拳闪不掉；身体拳照样中 |
| 下潜 / 摇闪 | 从勾拳下面钻过去 | 头部直拳、头部勾拳都躲开 | 上勾拳伤害 ×1.4，身体拳照样中 |
| 后仰（拉开） | 头往后让出 25 厘米，躲射程边缘的拳 | 刚好够到的头部拳会打空 | 身体拳照样中；背靠围绳时做不了 |
| 缠抱 | 贴身时锁住对手：喘口气、打断连击 | 双方都不能出拳，晕眩恢复加快 | 2 秒后裁判分开；一回合抱太多次会扣分 |

角度规则：进攻方站在防守方正面线 25° 以外时，防守方的格挡、拍挡、闪躲效果减半。
受伤（晕眩值高）的时候，防守效果也减半。

## 步法

| 技术 | 现实中的作用 | 模拟里怎么体现 |
|---|---|---|
| 前进 / 后退 | 控制距离 | 后退比前进慢 15% |
| 左右横移 | 绕圈、避开对手的强手一侧 | 横移比前进慢 20% |
| 轴转（左 / 右） | 以前脚为轴转身换角度，从围绳和角落脱身 | 3 帧内侧移约 0.5 米；对手正在出拳、收招或挨打时转身很慢，跟不上，就有了角度 |
| 举架压上 | 压迫型顶着刺拳往前走 | 半速前进，同时保持高位格挡 |

## 胜负

胜负只有三种：KO、TKO、点数判定（凑不出多数是平局）。规则以 ABC（美国拳击委员会协会）统一规则为准，联赛自己的选择单独标出。

**KO：被打倒，读秒数完还站不起来**

| 规则 | 内容 | 依据 |
|---|---|---|
| 什么算倒地 | 被合法击打后脚底以外的部位着地。模拟里有四种：一拳打中下颌等头部要害、一拳打中肝区（延迟 1~2 秒倒）、短时间连续挨打眩晕到线、身体伤到线 | 真实规则 |
| 读秒 | 每次倒地都至少数到 8，没有"站着读秒"。模拟里压缩成 3 秒 | ABC |
| 铃声不救人 | 读秒中（包括肝区击倒的延迟里）回合时间到了也要走完，最后一回合也一样 | ABC |
| 站不站得起来 | 看这一下越过抗击打线多少、本场累计伤害（体力）、第几次倒地，带运气。肝区倒地人是清醒的，但疼得很难站起来，按最重算 | 模拟近似 |

**TKO：没数完，但有人判定不能再打了**

| 叫停 | 情况 | 依据 |
|---|---|---|
| 裁判：累计伤害 | 体力（累计伤害）归零，已经无法继续 | 真实规则的精神：TKO 多来自累积挨打 |
| 裁判：无法自卫 | 被打晃（眩晕超过 60）后连续挨 8 拳，既不还手也不防守 | 真实规则的精神，8 拳是模拟里的数 |
| 三次倒地 | 一回合倒三次 | 联赛选择：ABC 统一规则不用，美国不少州在非冠军赛里保留 |
| 医生、角落 | 伤口伤病、扔毛巾、回合间弃权 | 暂不做：要先有伤口和角落模型 |

精力条（体能）耗尽不单独判 TKO：累垮的人手会掉、手肘护不住身体，更容易被打倒、被叫停，靠这条路间接影响。

**点数判定：打满全部回合**

| 规则 | 内容 | 依据 |
|---|---|---|
| 计分 | 三位裁判逐回合打 10 分制，赢的 10、输的 9 | 真实规则 |
| 有击倒的回合 | 打倒对方的人赢这一回合：倒一次 10-8、倒两次 10-7；双方都倒过就相互抵消，再按出拳判 | 惯例 |
| 扣分 | 一回合缠抱太多次扣 1 分 | 已有 |
| 裁判看什么 | 有效击打：重拳比刺拳分高，累了的软拳、擦到的打折，打在架子上的不算；三位偏好略有不同（看重拳 / 看手数 / 看压迫） | 已有 |
| 裁判不看什么 | 体力、体能剩多少 | 用户定的原则 |
| 结果 | 多数裁判判谁赢就是谁赢（一致、多数、分歧判定），凑不出多数是平局 | 真实规则 |

暂不做：取消资格、技术判定、无效比赛（要先有犯规系统）。

## 资源池（不判胜负）

- **体力**：本场累计伤害的反面，挨打就掉。体力越低，抗击打线越低（越容易被一拳打倒），倒地后也越难站起来；到 0 裁判判定无法继续（TKO）。比赛打满时裁判不看体力。
- **体能**：出拳、闪躲、走动都耗，回复 2.5/秒（乘体能属性）。持续出拳量被它卡住，越累伤害越低、步子越慢。
- **心态**：见上面"气势压制""心理战"。
- **晕眩**：头部受击累积，自然消退。超过 60 进入"受伤"状态：变慢、防守打折。到 100 就被击倒（连续挨打的倒地）。晕眩也会压低抗击打线，见"落点与击倒"。
- **身体伤**：身体受击单独累积，消退更慢。满了也会倒地（肝脏拳那种迟到的倒地）。
- **读秒**：倒地后读秒（压缩成 3 秒），对手回中立角。站不站得起来带运气，看三样：这一下越过抗击打线多少、本场累计伤害（体力）、这是第几次倒地。站起来也仍然带伤；站不起来就是 KO。一回合倒 3 次算 TKO。
- **裁判**：受伤状态下连续挨 8 拳、既不还手也不防守，裁判会终止比赛（TKO）。挨打时还在举架或闪躲的不算"不设防"，防住一拳或还手打中都会重新计数。
- **裁判打分**：每回合看有效击中，重拳比刺拳分高，被挡住的不算；击倒扣分（10-8），一回合缠抱太多次扣 1 分。
  三位裁判的偏好略有不同（一位看重拳，一位看手数，一位看压迫），所以会出现分歧判定。

## 落点与击倒（v9 头部，v10 身体）

干净打中的拳先按概率抽落点，再算冲击，和挨打者此刻的抗击打线比，越过得多越可能倒。运气由每场开打前定下的种子决定，种子存在回放里，重放结果一模一样。

| 环节 | 规则 | 依据 |
|---|---|---|
| 落点 | 下颌 / 头侧（太阳穴）/ 额头面门。直拳 30%/5%/65%，勾拳 45%/40%/15%，上勾拳 60%/0/40% | 起点，没有现成数据，用击倒率校准 |
| 下颌暴露 | 防守方低姿抱架（收下巴）×0.6，低手位 ×1.3，累垮手掉下来 ×1.3；进攻方这一拳熟练度 0.5→1.0 时 ×1.0→×1.2；射程边缘擦到的打不到下颌 | 收下巴、手掉下来是拳坛常识；累了手会掉是现有规则 |
| 冲击 | 伤害（已按天生下巴除过）× 落点系数（下颌 1.0、头侧 0.6、额头 0.25）× 拳种系数（勾拳 1.0、直拳 0.75、上勾拳 0.4）；没看见的拳 ×1.15 | KO 多数打在下颌（Hutchison 2014，UFC 录像）；职业 KO 复原都是勾拳打下颌侧（Cournoyer 2019）；实验室里拳手打假人，头部转动勾拳 > 直拳 > 上勾拳（Viano 2005；只用它定三种拳的相对大小，测的是奥运级拳手，职业拳更重）；提前绷紧脖子能减小头部晃动，证据弱，只给小加成（Eckner 2014） |
| 抗击打线 | 满状态 14.7；最近挨的打（晕眩）越多、本场累计伤害（体力）越重，线越低 | 定在"属性相同、满状态挨一记反击后手勾拳打中下颌约 25% 倒地" |
| 倒地概率 | 冲击不到线的三成不可能倒；过线后按 S 形曲线上升，坡度放得比较平 | 用户定：KO 多少由风格、策略、针对性决定，弱的一方要有一拳翻盘的机会。同一记反击勾拳：A（力量 0.8）打 B（抗击打 1.25）约 10%，B 打 A 约 57%；对方正在出拳时后手直拳打中下颌约 6%；被打晃时反击勾拳约 54% |
| 连续挨打 | 晕眩到 100 照样倒（不变） | TKO 比一拳 KO 多，TKO 前 30 秒平均挨 18.5 下（Hutchison 2014） |

**身体（v10）**：肝区击倒在比赛里确实存在、而且常见（ABC 的医学材料把它单列为一类击倒），只是"为什么会倒"（普遍的解释是迷走神经反射）没有对照研究，也没有"多少击倒来自身体拳"的统计。

| 环节 | 规则 | 依据 |
|---|---|---|
| 落点 | 肝区 / 心窝 / 其他（肋部、腹部、手肘上）。肝在人体右侧：左手勾拳 60%/5%/35%，右手勾拳 5%/5%/90%，直拳 15%/45%/40%，上勾拳左手 30%/40%/30%、右手 5%/55%/40% | 起点，没有数据，用击倒率校准 |
| 肝区暴露 | 对手站反架（右侧在前）直拳 ×1.3；累垮了手肘护不住 ×1.3；熟练度和打下颌一样加成；擦到的打不到肝 | 解剖位置、拳坛常识 |
| 冲击 | 伤害 × 拳种系数（勾拳 1.0、上勾拳 0.9、直拳 0.8），没看见的拳 ×1.15 | 起点 |
| 连续爆肝 | 肝区抗击打线随身体伤（打身体的累积）下降：同一记前手勾拳，满状态约 15%，身体伤 30 约 25%、60 约 50%、90 约 92% | 起点（用户确认过 15% 和 50% 两个点） |
| 倒的样子 | 延迟 1~2 秒才倒，期间弯着腰出不了拳、走不动、手护着肚子（没有自然站姿保护）；倒下后很难站起来 | 比赛录像里的常见样子 |
| 心窝 | 喘不上气：多扣 3 倍伤害的体能，2 秒内体能回复只剩三成；不会打倒人 | ABC 医学材料有描述，没有倒地数据 |
| 身体伤到线 | 照样倒（不变） | |

还没做的：太阳穴单独细分；"弯腰中"还没进 AI 的观测（为了能接着旧档训练，观测维度不变）。

## 身体参数（决定"出身"）

臂展、体重、力量、手速、步速（也决定转身快慢）、体能、抗击打、反应时间，再加上**站架**（正架 / 反架）。
正架打反架时前脚和强手的位置关系会变，这是真实拳击里的一个独立课题。

## 熟练度（决定"这个人用这一招是什么样"）

同一招，不同角色用出来不一样：身体条件定了上限（臂展→射程，力量→伤害，手速→快慢，步速→步法和转身），
熟练度决定用得好不好。每个角色对 22 项技术（12 种拳 + 高位格挡、护体、拍挡、侧闪、下潜、后仰、缠抱、轴转、虚晃、步法）各有一个 0~1 的熟练度，0.5 是普通。

| 技术 | 熟练度影响什么（0.5 → 1.0） |
|---|---|
| 各种拳 | 起手和收招快约 20%、伤害 +20%、耗体能 −20%、"擦到"的区间更窄 |
| 高位格挡 / 护体 | 挡掉的比例更高 |
| 拍挡 / 侧闪 / 下潜 / 后仰 | 时机窗口宽 1~2 帧、收招短、更省体能 |
| 缠抱 | 够得着的距离更远 |
| 轴转 | 一次转出去的距离更远 |
| 虚晃 | 更省体能 |
| 步法 | 走得快、转身快 |

**熟练度会自己演化**：起点是出身带来的天赋；训练里常用、用成功的技术越练越熟（成功的权重更大），不用的慢慢退回天赋水平。
所以"哪招好用 → 多用 → 更熟 → 更爱用"这条回路会自己长出招牌技和偏好。每个版本的熟练度都和网络一起存档。
双方都看得到自己和对手的熟练度（看过录像）。

## 第二批（基础技术跑通后再加）

肩滚防守（费城式）、抓挡、摆拳（过顶的后手）、勾拳转身（check hook）、刻意靠绳（rope-a-dope 是战术，应该能自己长出来，不单独做动作）。

## 真实度目标

动规则之前先定目标，之后不改目标去凑结果。`py -X utf8 calibrate.py --run <训练档>` 打 128 场 A 对 B，按下面的口径统计，结果追加到 `runs/<训练档>/calibration.jsonl`。

**总原则**（用户定）：
- 一切以画面效果和观看体验为主，也为以后的异种格斗打基础；AI 格斗家不要被保护得太好，要不择手段地变强。
- 武道家精神是最高的真理，也是真实格斗家毕生所求的顶点；赛博竞技场里，AI 格斗家有机会求得它。
- 但戏剧性来自理想和现实的碰撞。格斗家的性格和追求各不相同，并不都在第一天就知道该走哪条路；在一场场对战里，有些人有幸靠近武道之路。

**参照对象**：只参考职业拳击（用户定）。业余和奥运戴头盔、拳套大、计分和叫停规则不同，不当参照。有几条依据来自职业 MMA（UFC 录像研究），是因为找不到职业拳击的同类研究，已在各处注明。回合数和时长按节目效果和观看体验定，不照搬职业比赛（用户定：不用像现实那样顾及拳手的健康和职业生涯），所以按场算的数字（提前结束比例、每场击倒）不和职业比赛硬比。

**统计口径（对齐 CompuBox）**：出拳 = 打出去的拳（虚晃不算）。命中 = 干净打中；打在举起的架子上、被闪掉、打空都不算；射程边缘擦到的不算；没举架时自然站姿挡掉一部分的，按挡剩的比例折算（手本来在脸边，有一部分拳会打在手套上）。重拳 = 刺拳以外的拳。

| 指标 | 目标 | 类型 | 依据 |
|---|---|---|---|
| 每分钟出拳（每人） | 18~22 | 真实数据 | 职业约 19.5（ESPN 2012，CompuBox 次中量级平均每回合 58.4 拳）；重量级拳王赛约 12.5（Finlay 2022）。只参考职业，不参考业余和奥运 |
| 总命中率 | 30%~40% | 真实数据 | 职业平均约 32%（ESPN 2012）；重量级拳王赛 34.6%（Finlay 2022，PLOS ONE） |
| 刺拳命中率 | 18%~30% | 真实数据 | 没有公开的总平均，由总命中和重拳命中推算约 22%~26% |
| 重拳命中率 | 30%~45% | 真实数据 | CompuBox 平均 36.9%（Bad Left Hook 2019） |
| 累垮时间占比（体能 < 25%） | 两成以下 | 设计约束 | 不是统计数据：真实拳手不会整场空着油箱打 |
| 最常用架势的时间占比 | 六成以下 | 设计约束 | 没有一种架势被所有角色都用超过六成时间 |
| TKO 的原因分布 | 不设 | 只记录 | 体力归零、连续挨打不还手、一回合倒三次各占多少（v10 起体力归零判 TKO 是规则的一部分） |
| 提前结束比例（KO+TKO） | 偏高是好事，不设上限 | 只记录 | 用户定：对抗激烈、观众爱看 KO 和 TKO，有的风格本来就追求 KO，不按职业比例压低。参照：职业 47%（KO 15%、TKO 32%，BoxRec 2014~2024，会议摘要）。要留意的是结局别全被一方包办 |
| 每场击倒次数 | 不设 | 只记录 | 没找到可靠数据 |
| 提前结束发生在最后一回合的比例 | 不设 | 只记录 | 真实比赛偏早段（Hutchison 2014 UFC 录像研究；职业平均第 2.59 回合） |

**b2 v50 基准（box2d-v8，128 场）**：每分钟出拳 36.4，总命中 63.6%，刺拳 69.1%，重拳 33.8%（达标），累垮 81.5%，最常用架势 82.8%，TKO 102 场全是血条归零，没有击倒，提前结束 90% 发生在第 3 回合。

## 实验记录

### 实验 1：开场狂打、累垮、不防守，是训练的问题还是规则的问题（2026-10-09 开始）

**起因**：对抗评审发现两件事。一是训练的折扣是每帧 0.995，半衰期只有 6.9 秒，开场时比赛胜负的权重只剩约千万分之三。二是每打中一拳就给分的奖励，一场加起来是胜负奖励的 1.6 倍。所以 AI 实际在学"接下来 7 秒比对方多得分"。v6、v7 改过两次体能规则，都没改掉"空着油箱打"，也说明问题可能不在规则。

**做法**：比赛规则一条不动，都从 b2 v50 接着训 300 轮。检查点里没有价值网络，先热身 10 轮只练价值网络。三组，每组两个种子（11、12），其余设置相同：

| 组 | 折扣（半衰期） | 奖励 |
|---|---|---|
| 对照 | 0.995（6.9 秒） | 不变：每分 0.02、击倒 0.3、胜负 ±1 |
| 甲：看得更远 | 0.999（34.7 秒） | 不变 |
| 乙：看得更远、只看胜负 | 0.999（34.7 秒） | 只有胜负 ±1（判定也是胜负），去掉每拳给分和击倒奖励 |

**事先写下的预测**（结果出来前定，用 calibrate.py 的口径判）：
- 如果"看不远"是主因：甲、乙两组的两个种子，每分钟出拳都比对照组低至少三成，累垮时间占比都不到对照组的一半。
- 达不到这两条，就否定"看不远是主因"，回头查规则。
- 乙组和甲组差别大，说明每拳给分的奖励本身在扭曲打法。
- 对低手位不做预测，那是实验 2 的事。

**中途（第 50 轮，热身后实际只学了 40 轮）**：三组的出拳和累垮都和对照组差不多，还看不出差别，按事先说好的，以第 300 轮为准。意外的是乙组（只看胜负）两个种子都变成 A 压倒性赢（114:14、118:10），B 举架和闪躲的时间从 7%~11% 涨到 19%~21%。

**补充检验：现有规则下花光体力吃不吃亏**（事后加的，不在事先预测里）：不重新训练，强制一方体能低于 θ 时不准出拳，各打 256 场。

| 强制谁省体力 | θ=0（不强制） | θ=0.25 | θ=0.40 | θ=0.60 |
|---|---|---|---|---|
| B 的胜率 | 46% | 60% | 87% | 94% |
| B 每分钟出拳 / 累垮占比 | 32.3 / 70% | 26.7 / 49% | 30.4 / 4% | 30.4 / 2% |
| A 的胜率 | 49% | 23% | 14% | 4% |
| A 每分钟出拳 / 累垮占比 | 40.3 / 92% | 16.5 / 89% | 13.3 / 33% | 7.8 / 20% |

- B 只要别在体能四成以下出拳，出拳量几乎不变，累垮从 70% 降到 4%，胜率从 46% 涨到 87%。规则本身已经让"花光体力"很吃亏，B 没学会省，是学法的问题。网络没为这个规定重新适应过还能涨这么多，这是强证据。
- A 被强制省体力反而输得更多：出拳量掉了一大半，体能还是被后退和横移耗着。但 A 的网络整套打法都建立在高出拳量上，没机会重新适应，所以这一条只能说明"A 现在的打法离不开狂打"，不能说明省体力对 A 不划算。
- 现在 A、B 五五开，是两边都打得不好凑出来的平衡。

**结果（第 300 轮，calibrate.py 口径，各 128 场）**：

| 组 / 种子 | 每分钟出拳 | 累垮 | 总命中 | 刺拳 | 重拳 | 最常用架势 | 击倒/场 | A 胜 : B 胜 |
|---|---|---|---|---|---|---|---|---|
| b2 基准 | 36.4 | 82% | 64% | 69% | 34% | 83% | 0.00 | 65:59 |
| 对照 s11 / s12 | 33.9 / 33.7 | 84% / 85% | 65% / 68% | 70% / 75% | 47% / 44% | 80% / 73% | 0.02 / 0.01 | 48:62 / 23:93 |
| 甲 s11 / s12 | 31.4 / 27.2 | 77% / 85% | 68% / 63% | 75% / 74% | 53% / 42% | 83% / 68% | 0.01 / 0.02 | 40:88 / 49:67 |
| 乙 s11 / s12 | 23.4 / 23.0 | 77% / 87% | 32% / 64% | 25% / 69% | 36% / 58% | 57% / 74% | 0.14 / 0.02 | 7:113 / 42:83 |

- **事先的预测不成立**：出拳只有乙组降够了三成，累垮时间三组都没降。"看不远是主因"被否定。
- **每拳给分的奖励确实在推高出拳量**：去掉以后两个种子都降了约三成，而且是逐步降下来的；只拉长时间只降了一到两成。
- **累垮没降，是因为体能花得和回得一样快**：分人拆开看，每个人每分钟花在出拳、走动、挨身体拳上的体能加起来，刚好等于能回复的量。所以体能一直贴着底，从来不存一点余量。补充检验已经证明存余量很值钱（B 留四成就能从 46% 胜率涨到 87%），可三种训练设置练 300 轮都没学出来。
- **新的判断**：问题既不在"看不远"，也不在"规则不罚累垮"，而在"学不出来"。"一直留着余量"要连续很多帧都忍住不打，好处很晚才显现，靠每帧随机试动作几乎碰不到。这是下一步要验证的假设。
- **乙组 s11 有四项进了真实范围**（总命中 32%、刺拳 25%、重拳 36%、最常用架势 57%），还出现了击倒，但 s12 没有重现。两个种子差这么多，这一条不能当结论，只能说明强化学习的结果波动很大，一个种子不够。

### 实验 1b：留余量是不是"学不出来"（2026-10-09 开始）

**假设**：实验 1 里留余量很值钱，但 AI 学不出来，因为要连续很多帧忍住不打，靠每帧随机试动作几乎碰不到。

**做法**：设置和实验 1 的乙组相同（折扣 0.999、只看胜负、从 b2 v50 接着训 300 轮、热身 10 轮、种子 11 和 12）。唯一的区别是"留力训练"：训练时每场开打前抽签，一半的比赛给双方各设一条体能线，线在 20%~60% 之间随机。体能低于这条线时不准出拳，能走、能防、能抱。体能线只在训练时有，AI 看不到它；评估和正式比赛都不设线。对照组就是实验 1 的乙组，不重跑。

**事先写下的预测**（calibrate.py 口径，正式比赛不设线）：
- 如果"学不出来"成立：两个种子的累垮时间都低于 41%，也就是不到乙组平均 82% 的一半。
- 达不到，就否定这个假设，再查观测（AI 看不看得到自己的体能、看得准不准）和网络结构。
- 顺带记录：出拳量、命中率、胜负。这几项不做预测。

**结果（第 300 轮，各 128 场）**：

| 组 / 种子 | 每分钟出拳 | 累垮（A / B） | 总命中 | 刺拳 | 重拳 | 最常用架势 | 击倒/场 | A 胜 : B 胜 |
|---|---|---|---|---|---|---|---|---|
| 乙（对照）s11 / s12 | 23.4 / 23.0 | 77%（89/65）/ 87%（87/88） | 32% / 64% | 25% / 69% | 36% / 58% | 57% / 74% | 0.14 / 0.02 | 7:113 / 42:83 |
| 留力训练 s11 / s12 | 19.9 / 18.5 | 70%（79/61）/ 57%（78/35） | 28% / 26% | 30% / 17% | 27% / 29% | 39% / 59% | 0.08 / 0.19 | 18:104 / 4:116 |

- **事先的预测不成立**：累垮 70% 和 57%，没降到 41% 以下。不过方向对了：比乙组平均少了约 18 个百分点，从第 150 轮（86%、90%）到第 300 轮还在往下走。
- **顺带的变化，两个种子一致**：出拳量进了真实范围（19.9、18.5），总命中降到 26%~28%，略低于目标下限，架势分散了（最常用架势 39%、59%，都低于六成），开始出现击倒。（实验 1c 接着练以后，除了出拳量，这些改善都没保住。）
- **事后补做的检验**（不在事先预测里）：用乙组和留力训练组练出来的模型重做"强制留余量"。B 留四成余量，胜率在四个模型里分别是 89%→100%、75%→94%、80%→99%、87%→97%；乙组 s12 的 A 是 25%→60%。双方都调整过打法之后，留余量照样很值钱，可 AI 还是只学会了一部分。
- **判断**：现有规则对累垮的惩罚已经够重，瓶颈在训练学得慢，规则这边不用为体能再改。留力训练有用，但 300 轮不够。
- **新问题**：只看胜负以后，四个模型里三个是 B 压倒性赢。出拳量降下来以后，B 的力量、抗击打、体能更占便宜，A 靠手速和出拳量换来的优势没了。属性预算是在狂打的打法下配平的，打法变了，平衡也要重新配。

### 实验 1c：留力训练练得更久（2026-10-09 开始）

**做法**：从实验 1b 两个种子的最终模型（x1b_floor_s11、s12 的 v6）接着练 500 轮，设置和 1b 完全相同（折扣 0.999、只看胜负、一半比赛设 20%~60% 的体能线、热身 10 轮）。

**事先写下的预测**（calibrate.py 口径，正式比赛不设线）：
- 两个种子的累垮时间都低于 41%（和 1b 同一条线）。达不到，就说明光靠练得更久不够，要换训练方式（比如训练营里专门练节奏、或者让 AI 有记忆）。
- 出拳量保持在每分钟 18~22。
- 命中率、架势、胜负只记录，不做预测。

**结果（各 128 场；v5 = 续练 250 轮，v10 = 续练 500 轮）**：

| 种子 / 版本 | 每分钟出拳 | 累垮 | 总命中 | 刺拳 | 重拳 | 最常用架势 | 提前结束 | A 胜 : B 胜 |
|---|---|---|---|---|---|---|---|---|
| s11（1b 结束时） | 19.9 | 70% | 28% | 30% | 27% | 39% | 53% | 18:104 |
| s11 v5 / v10 | 21.5 / 20.3 | 83% / 78% | 51% / 53% | 63% / 70% | 31% / 35% | 70% / 82% | 24% / 29% | 38:80 / 31:73 |
| s12（1b 结束时） | 18.5 | 57% | 26% | 17% | 29% | 59% | 62% | 4:116 |
| s12 v5 / v10 | 23.8 / 21.8 | 85% / 82% | 65% / 58% | 77% / 73% | 55% / 40% | 60% / 65% | 87% / 23% | 17:111 / 92:33 |

- **事先的预测不成立**：累垮 78% 和 82%，比 1b 结束时还高。出拳量保持在范围里。
- **1b 的几项改善没保住**：命中率回到五六成，刺拳又回到七成，低手位又占了大头。1b 结束时那一刻的好数字，是自我对练来回摆动中的一个点，不是稳定下来的打法。以后判断一次训练的效果，要看几个版本的走势，不能只看最后一个快照。
- **判断**：光靠练得更久不够，留力训练也只能让 AI 一时学会留余量。按事先说好的，要换办法。
- 胜负在两个种子之间来回翻（s12 从 B 压倒到 A 压倒），说明 A、B 的强弱还没稳定，现在谈重新配平还太早。

### 实验 2：按落点判击倒、血条不判胜负（box2d-v9，2026-10-10 开始）

**假设**：累垮了手掉下来、下巴暴露，干净一拳就可能被打倒，累垮的代价会在几秒内兑现，落在 AI 看得到的时间里，所以 AI 会学着留余量。

**做法**：训练设置和实验 1 的乙组完全相同（折扣 0.999、只看胜负、从 b2 v50 接着训 300 轮、热身 10 轮、种子 11 和 12、没有留力训练），只把规则换成 v9。乙组是在 v8 规则下测的，留作参照。

**事先写下的预测**（calibrate.py 口径；吸取 1c 的教训，取第 200、250、300 轮三个版本的平均，不只看最后一个）：
- 两个种子每场击倒都不少于 0.2 次。
- 两个种子累垮时间都低于 41%。达不到，就说明"击倒的危险"也教不会 AI 留余量，改用角落的"保留体能"计划。
- 血条归零判的 TKO 按规则就是 0，不算预测。提前结束比例、命中率、架势、胜负只记录。

**开训前**：b2 v50 不重新训练、直接换 v9 规则打 128 场：每场击倒 0.14 次，KO 7%、判定 70%、平局 23%，累垮 84%，出拳和命中和 v8 下差不多，A 胜 78、B 胜 21。

**结果（v4 / v5 / v6 = 第 200 / 250 / 300 轮，各 128 场）**：

| 种子 / 版本 | 每分钟出拳 | 累垮 | 击倒/场 | KO | 判定 | 总命中 | 刺拳 | 重拳 | 最常用架势 | A 胜 : B 胜 |
|---|---|---|---|---|---|---|---|---|---|---|
| s11 v4 / v5 / v6 | 29.7 / 26.0 / 19.8 | 57% / 62% / 62% | 1.89 / 1.66 / 1.42 | 74% / 66% / 52% | 12% / 22% / 34% | 23% / 27% / 30% | 20% / 24% / 23% | 26% / 29% / 34% | 43% / 44% / 32% | 3:124 / 9:111 / 8:106 |
| s11 三版平均 | 25.2 | 60% | 1.66 | 64% | 23% | 27% | 22% | 30% | 40% | |
| s12 v4 / v5 / v6 | 29.3 / 24.5 / 20.4 | 79% / 74% / 67% | 1.70 / 1.65 / 1.65 | 82% / 75% / 58% | 10% / 19% / 23% | 58% / 52% / 31% | 71% / 55% / 41% | 44% / 50% / 28% | 63% / 64% / 39% | 10:115 / 18:107 / 9:111 |
| s12 三版平均 | 24.7 | 73% | 1.66 | 72% | 17% | 47% | 56% | 41% | 56% | |

- **事先的预测一半成立**：击倒每场 1.66 次，远超 0.2；累垮 60% 和 73%，没降到 41% 以下。比乙组（77%、87%）少了一些，"击倒的危险能教会留余量"只有一部分效果。
- **KO 比真实职业比赛多得多**：三版平均 KO 占 64% 和 72%，职业比赛 KO 约 15%（加上 TKO 共 47%）。用户定：KO 多是好事，说明对抗激烈，观众就爱看 KO、TKO，有的风格本来就追求 KO，所以不按职业比例往下压。
- **真正的问题是 KO 几乎全是 B 打 A（106~124 胜）**，比赛没有悬念：一拳击倒是"过线"规则，力量和抗击打的差距被放大了。B 力量 1.25 打抗击打 0.85 的 A，伤害是基准的 1.47 倍；A 打 B 只有 0.64 倍。属性预算按线性给分，可击倒是门槛效应，力量和抗击打的"分价"要重估。
- **走势还没稳**：从 v4 到 v6，出拳降到每分钟 20 左右（进了目标），架势越来越分散（最常用架势 32%、39%），KO 比例在降（74%→52%、82%→58%）。s11 的命中率三版都在 23%~30%。按 1c 的教训，这些还在变，不能当最终结论。

### 实验 3：v10 规则下有没有爆冷、风格有没有差别（box2d-v10，2026-10-10 开始）

**问题**：用户定的方向是 KO 多少由风格、策略选择、针对性和爆冷决定。v10 把击倒曲线放平、加了肝区，要看两件事：弱势一方有没有真实的赢面（尤其靠 KO 翻盘）；追求 KO 的打法和拿分的打法，结局是不是明显不同。

**做法**：训练设置和实验 2 完全相同（折扣 0.999、只看胜负、从 b2 v50 接着训 300 轮、热身 10 轮、种子 11 和 12），只把规则换成 v10。训练时每场随机抽战术计划（训练本来就是这样）。评估取第 200、250、300 轮三个版本的平均：出拳、命中、爆冷用双方自由发挥打 128 场；风格用每场随机抽计划打 256 场。

**事先写下的预测**：
- 爆冷：两个种子弱势一方的胜率都不低于 15%，而且弱势一方的胜场里至少三成靠 KO 或 TKO。
- 风格：两个种子里，"重拳抢攻"的提前结束比例都比"稳拿分数"和"外围控距"高至少 10 个百分点。达不到，说明战术计划塑造不出风格，要回头改计划的设计。
- 只记录：KO / TKO / 判定比例、TKO 原因、累垮、出拳、命中、架势、胜负。

**结果**：待填。
