# 职业拳击防守、步法、架势：用途与情境

## 一、防守

**1 默认护头**　目的：出拳间隙不留空档。前提：后手贴下巴、肘贴肋；收拳别仰下巴后撤，往下打刺拳会吃后手反击[22]。风险：只靠被动护架会挡视线、难反击、费体力[4]。人群：所有人。

**2 高位格挡（标准高位架）**　目的：不离开距离就把拳吃掉。情境：中近距离挡刺拳、快拳手、整串组合[3][4]；挡的瞬间屈膝沉重心、呼气，免得被推着走[18]。后续：挡完马上还击[3]。风险：仍吃部分力，被重拳推退，挡视线，缩成龟壳只招来更多拳；上勾拳用手挡不住，要用肘或前臂[3][9]。人群：反应偏慢、上身少动的人[22]；Winky Wright、Arthur Abraham[33]。

**3 护体**　情境：身体刺拳、身体勾拳，直接挡比闪容易[1]。做法：架子下压、身体迎向来拳、后肘或前臂接[22]；来不及就呼气绷腹、转体或后撤[17]。后续：近身短勾、上勾。风险：用手往下拨会空出下巴、吃左勾[22]；对手常用身体刺拳引下你的手再打头[26]。

**4 拍挡 parry**　目的：小幅拨偏来拳，借对方前冲制造空档[5]。情境：只拍直拳，勾拳、上勾拳别拍[5][30]；被困、没地方移动时用[32]。前提：先会格挡，手不追拳、动作小[5]。后续：下拍后从上面还击，侧拍右直拳后接左勾[5]。风险：被假动作骗开，拍空就吃重拳，对组合和身体拳效果差[3][5]。人群：技术型、反击型。

**5 侧闪 slip**　目的：完全躲开，双手空着马上反击[3]。情境：闪对方投入的大拳（后手直拳为主），别闪第一记刺拳（他还没投入）；往外侧闪，别往内侧（拳路向内弯）[1][2]。前提：看清再动，腿髋发力，头先偏一侧做诱饵[2][21]。后续：闪刺拳接后手直拳，闪右直拳接左勾[2]。风险：没闪干净就被打实；老往同一边闪会被预判[1]，Cotton 就是读出 Torres 的闪躲节奏，在他闪到一半时打中右手[29]。人群：反应快的人，对付更快或更高的对手[3]。

**6 下潜 / 摇闪**　目的：从勾拳下钻过、贴近、换角度，让头成移动靶[30][31]。情境：头部勾拳、摆拳，要缩短距离时[11][30]。前提：屈膝不弯腰，幅度越小越好[2][32]。后续：起身打勾拳、身体拳、上勾拳[11][32]。风险：前倾正好送给上勾拳[9]；对手打身体、压你的头、绕到侧面，弯腰时脚走不动[10]；蹲到对方腰带以下在内华达规则里算犯规[39]。人群：矮个压迫型，如 Tyson、Chavez[27]。

**7 后仰 pull back**　目的：让直拳落空，原地反击。情境：单记刺拳或直拳；Mayweather 站在打击圈外诱刺拳，后仰偏左再回后手直拳[26]。前提：距离读得准；Dempsey 说这是直拳的最后手段，绝不用来躲头部勾拳[30]，expertboxing 则认为可后仰躲勾拳和上勾拳[11][9]。风险：被看出规律后对手多跟一步；Wylie 指出 Mayweather 这个动作有可见预兆（抬后脚跟、重心移向前脚）[26]；假右真左勾专打后仰的人[26]。人群：高个、距离感好的反击型[11]。

**8 缠抱 clinch**　何时：被打晃、累了、要喘口气、眼睛进东西或手伤[12][13]；对方打出节奏时先出手再抱，或打完一组马上抱住防反击（Mayweather）[24]；用夹臂压住对方前手（Ward）[25]。为什么：贴身后对方的拳打不疼，也没法靠走位让你落空[14]。前提：贴进要坚决，头高过对方[12]。裁判：内华达规则把"抱一只手打另一只手""故意维持缠抱""分开时打""推搡"列为犯规，裁判应警告，可扣分或取消资格[39]；Klitschko 就因抱压 Povetkin 被扣 1 分[40]。风险：抱多了被警告扣分，抱的空当被打。

## 二、步法

**9 进退步**　目的：进出打击距离。情境：他出拳时你动，你出拳时他动；退到拳落空就停，等他组合打完再踏回[16]；每拳只让几英寸，先动头、再动髋、最后才动脚[15]。风险：退过头就打不到人[22]；一直跑耗光体力、让出场地[15]，消极也丢判定[3]。人群：外线型、臂长者。

**10 横移**　目的：离开中线、制造新角度[16]。情境：对付直线压进型。风险：横移不到位头还在距离内[16]；切角者有"双向威胁"，往他左边绕迎上左勾，往右绕迎上右勾，迎着走挨得更重[27][28]。方向：绕离对方强手（教练经验）。人群：外线型、技术型。

**11 轴转 pivot**　目的：转开换角度、让出空间，离开绳边角落[27]。情境：被逼到绳边时以前脚为轴转出[35]；上步加转体，脚落地同时出拳[30]；对弯腰的下潜者绕转[10]。风险：好的切角者不跟着转，而是横跨拦截，轴转就只换来一点空间[27][28]；转向对方强手侧会吃勾拳（教练经验）。人群：反击型、被压迫的一方。

**12 靠绳与脱离**　为什么不好：站架塌、脚下没根，要出去就得撞向对方某只手[28]。脱离：变向，在切角者踏步那一下反向，配合下潜换高度[27]；前脚为轴转出、边走边打，或抱住转身把对方送上绳[12][35]。rope-a-dope 何时有效（据[36]归纳）：对手拳重但体能可疑，你护架紧、抗打，他大量打在手臂上，你抓空当短促反击。例子：Ali 对 Foreman 第 8 回合反击 KO[36]；Mayweather 靠绳省体力[24]。风险：被钉住吃终结拳[35]；对手有选择地出拳、把拳塞进防守间隙就破了[24]。研究：一项职业赛研究（15 场一二回合结束的比赛）发现胜者多在靠近擂台中央的区域作战[45]。

**13 切角封堵**　做法：他往左你往左，他往右你往右，用侧步拦住沿绳退路，往角落赶；别跟着他转身，那样只是在新线上重建距离[8][27][28]；Roach 批评 Pacquiao"跟着 Mosley 跑，而不是拦住他"[34]。前提：防守够好、不用后退，先用轻拳推压[8]。后续：对方背靠绳只剩 180°，两手两边封，再上重拳[27]。风险：冲太近他会从侧面溜走，太早上重拳易被抱[8]；切角者一定会挨打，也会被方向假动作骗得过早上步[27]。人群：压迫型，如 Saddler、Foreman[27]。

## 三、架势

**标准高位**：见第 2 条。护脸和中线、最能挡组合，代价是挡视线、难反击、费力[4]。

**长架**：伸出的前手检查、拍、压对方前手，让他绕远路，控距离[27][38]。护不住越过前手的直拳和上勾拳；出重拳得先收手，有预兆；前侧身体暴露；对手横移能在你收手前钻进来[38]。适合身高臂长者[38]，代表 Saddler、Foreman[27]。

**低姿抱架 / peek-a-boo**：拳贴颊、肘贴身，靠不停的头部移动[37]；D'Amato 体系用头部移动找空档，再打成串重拳[29]。护不住：固定的闪躲节奏会被读[29]，被抓住容易 KO，往里走必挨拳[7]。前提：体能、头部移动、力量、下巴[7]。适合矮壮短臂、高能量型，高个不该缩架[7]。代表 Patterson、Tyson、Torres[29][37]。

**低手位 / Philly shell / 肩卷**：前肩转进来卸后手直拳，刺拳和勾拳靠后手挡拍，髋部顺势"上弦"打后手反击[26]；滚动能化解整串强拳[3]。护不住：刺拳、假动作、滚错方向[3][6]；对左撇子效果下降，Mayweather 对左撇子改用常规护架[23][24]；身体刺拳能诱开后手[26]。适合节奏好、经验足的反击型[3]，代表 Toney、Whitaker、Mayweather[6]。

**换站架**：目的是改变对位角度、打乱节奏（教练经验）。职业拳手多是短暂换架（[19]读者讨论举 Hagler 等例）。风险：弱侧精度和力量差，压力下会退回强侧[19]；Wylie 劝别换得太频繁，两边都强的只有 Hagler、Hamed、Crawford 等少数人[23]。

## 四、看见再反应，还是预判？

- 时间：Piorkowski 等从"动作开始"算起，测得直拳约 357ms、勾拳约 477ms，认为能识别早期信号的防守者时间比以前以为的多[41]；另一研究称一拳通常 <200ms、接近反应时，所以闪躲要靠出拳前的身体动作信息[42]。
- 研究：格斗专家预判比新手准，靠出拳前和出拳中的信息，目光锚在对手躯干或头部、余光看手脚（Ripoll 1995 为转述）[42][43][46]；单纯反应时不能明显预测成绩[43]。2022 年元分析中拳击亚组差异不显著[44]。以上研究样本都不是职业拳手，没找到研究职业拳手用什么信号的论文。
- 权威说法：Wylie 说反击型拳手靠"读和卡时机"，Mayweather 靠模式识别吃对手的习惯，"假动作是好时机感的克星"[23][24]。expertboxing 反对盯肩膀、胸口（都可能是假动作），主张看整个上身、用余光、靠练出的自动反应[20]，并把"预判对方对你某拳的惯用回应"列为第二级防守[4]。
- 综合（本报告推断）：近距离主要靠预判（习惯、节奏、距离）加自动化动作；远距离、路线长的拳才有看见再反应的余地。肩膀和重心是信号，但会被假动作利用。

## 五、情境 → 防守

- 刺拳：后手接拍、格挡、外闪（不闪第一记）、后撤半步[1][5]
- 后手直拳：外闪接反击、肩卷、拍挡、后仰反击[1][5][6][26]
- 勾拳：下潜摇闪、护架加肘硬挡；不拍[5][11]
- 上勾拳：肘或前臂挡、侧身、后仰；别前倾[9]
- 打身体：肘和前臂挡、呼气绷腹、转体、后撤[17][22]
- 连续组合：护架全挡、肩卷滚动、小步退到落空、抱住[3][4][16]
- 被逼绳边：收紧护架，变向或轴转出，抱住转身换位[27][35]
- 被打晃：抱住压住，换方向换高度走动，低头护架[13]
- 自己累了：抱，高位护架小步走，占中央，用假动作代替真拳[14]
