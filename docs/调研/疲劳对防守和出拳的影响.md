# 疲劳对防守和出拳的影响

2026-10-10 调研（子任务查证）。业余样本的行为数据（护手、节奏）只当旁证；生理数据不限样本。方括号是来源编号。

## 1. 护手会不会掉

- 唯一有测量的是业余：Dunn 2017，26 名澳洲精英业余，3×3 分钟。"护手下垂时间"第 1→2 回合增加（效应量 0.46），1→3 回合增加（0.66）；同时抱缠变多、弹跳变少。作者认为部分是主动省力。局限：业余 3 回合，只给效应量，没有手的高度或秒数。[1]
- 职业拳击：没查到测手的高度或护头时间比例的研究。
- 教练经验：ExpertBoxing 的 Johnny Nguyen 写"后段肩膀烧起来时，没力气再把手套举着，出拳也没了脆劲"。[2]

## 2. 反应、决策、防守

- 拳击分级疲劳：20 名业余，心率 160/180/200 时测，反应速度 2.36→2.35（无差异）→2.16 次/秒，到 200 才慢约 9%；敏捷跑 −2%→−10%。局限：业余，点触屏任务。[3]
- 拳击实战对练：7 名国家级，3×3 分钟，第 3 回合后后手直拳反应时显著延长（最高 390ms），出拳力反而上升。局限：n=7，摘要无基线。[4]
- MMA：45 人，30 秒上肢冲刺后简单反应 266→270ms（+1.5%），波动增大 14.7%。局限：只测手指按键。[5]
- 空手道：12 人，击打至疲劳后出拳反应 +10~12%。局限：非精英。[6]
- 闪躲、格挡成功率：没查到直接研究。旁证：11 名半职业橄榄球员做冲刺加擒抱循环，擒抱技术第 1、2 轮后 −10%、−15%，第 4 轮后 −34%。[7]

## 3. 出拳

- 力量：10 名业余做下肢循环后 −4.26%；后手直拳 −7%、左勾 −8%、刺拳几乎不变，各人最弱的拳 −9.8%。局限：n=10，非拳击式疲劳，正文数字有前后不一。[8] 另一项 28 名高水平业余划船后所有拳种都降，后手和勾拳降得多（摘要无百分比）。[9]
- 速度：21 名精英 MMA，90~120 秒高强度徒手练后直拳速度 8.4→7.5 m/s（−11%），冲击力 −11%，关节角变异系数约 4%→6~7%。局限：实验室短时疲劳。[10]
- 准确度：拳击无直接数据。网球打到力竭时落点准确度 −69%、发球 −30%，这是力竭端点值。[11]
- 实战反例：传感手套测 6 场职业赛，其中两场（4 回合、6 回合）逐回合分析，力量无显著下降，一场末回合反而更大（1098 对 898 牛）。局限：回合少。[12] Dunn 论文里拳击对练式疲劳后出拳力也没显著变化，作者归因于节奏分配。[13]

## 4. 职业比赛后段

- 没查到系统研究。CompuBox 逐回合数据大多不公开。135 场重量级冠军赛的研究只给全场平均：每回合 37.6 拳、命中 34.6%。[14]
- 个例：Boxing Science 的 Danny Wilson 分析戈洛夫金，出拳间隔从第 1 回合 3 秒缩到第 8 回合 2 秒；对手 1~4 回合增加、4~8 回合减少。局限：样本未说明。[15]
- 结论："后段被命中率上升"目前既无数据支持也无数据否定。

## 5. 体力分配

- 体能专家 Ruddock：节奏原则上由战术决定，可开局抢 3 回合再稳住，或逐回合加码；平均每回合约 60 拳。属实践者观点。[16]
- 教练经验：回合最后 30~60 秒发力"抢回合"，利用裁判的近因印象。[17]
- 业余数据：护手下垂、少弹跳被解释为控制疲劳的节奏策略。[1]

## 6. 阈值还是渐变

证据指向"先平后陡的连续曲线"，不是开关：
- 22 名足球员递增负荷：选择反应先变快，约 75% 最大摄氧量时最快（降到安静值 87%），之后迅速变慢，最终比安静慢 18%。[18]
- 拳手分级：反应在心率 160→180 不变，200 才降。[3]
- 擒抱逐轮降、末轮加速；网球 −69% 只出现在力竭点。
没找到"到某个体能值突然全面失效"的证据。

## 建议（子任务的归纳）

形状：分段平滑。体能 100%→约 50% 基本无损；50%→20% 缓降；20% 以下加速。不要在 25% 处跳变。体能接近 0 时的极限值参考：
- 出拳力 −5%~−10%，后手和勾拳比刺拳降得多（有证据）。实战里力量几乎不掉，靠的是少出拳。
- 出拳速度约 −10%（有证据，MMA 样本）。
- 反应：中段几乎不变，极度疲劳慢约 10%（各研究 1.5%~18%），约 15~45ms。
- 动作散布增大五到七成（有证据），可以用命中偏差变大来表现。
- 护架：随回合逐渐掉有证据（中等效应），"完全失效"没有证据，掉多少只能按常识。建议默认护架从体能 50% 开始线性降，最低保留约一半。
- 护手下垂部分是主动省力，可以做成 AI 可选的动作：放低手换体力回复，代价是更容易挨打。

只能按常识：护手具体降幅、闪躲格挡成功率降幅、拐点位置、职业后段被命中率变化。
